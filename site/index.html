찾고, 고치고, 다시 확인해요

코드를 점검해서 위험한 곳을 찾아요. 고치는 방법을 알려 주고, 정말 뚫리는지 안전한 연습장에서 확인한 뒤, 고친 코드로 다시 한 번 확인해요. 개발 전문가가 아니어도 읽을 수 있게 쉬운 말로 알려 드려요.

한 번에 네 가지를 해요

집을 점검하는 일에 빗대면 쉬워요. 먼저 잠기지 않은 문을 찾고, 어떻게 잠글지 알려 주고, 정말 열리는지 시험해 보고, 잠근 뒤에 다시 시험해요.

전문 용어로는 1번 = SAST(코드 정적 분석), 3~4번 = DAST(실행 중인 앱을 공격해 보는 검사)와 패치 검증이에요. 3번은 인터넷과 분리된 샌드박스 안에서만 일어나요.

위험도는 집에 빗대어 읽어요

색을 구분하지 못해도 알 수 있게 모양과 글자를 같이 써요.

  • 심각현관문이 활짝 열려 있어요. 지금 바로 고쳐요.
  • 높음창문 잠금이 헐거워요. 빨리 고쳐요.
  • 보통담장에 작은 틈이 있어요. 고치면 좋아요.
  • 낮음우편함에 이름이 보여요. 참고해요.

이런 점이 달라요

  • "찾았다"에서 끝나지 않고 고치는 코드까지 줘요.
  • 찾은 문제가 정말 위험한지 실제로 시험해 봐요(연습용 표적).
  • 고친 코드도 다시 시험해서 막혔는지 확인해요.
  • 설명은 "남의 명령을 내 서버에서 실행할 수 있어요"처럼 무슨 일이 생기는지로 써요.

실제로 뚫리는지 확인

연습용으로 만든 취약한 앱에서, 점검이 찾은 문제 중 XSS(남의 스크립트 실행)와 SQL 인젝션(데이터베이스 조작) 한 곳씩을 샌드박스에서 실제로 재현해 확인했어요. 나머지는 "확인 못 함"으로 표시해요. (연습 표적 1종 · Sprint 52 검증 기록)

고치는 방법의 품질 베타에서 측정 중

제안한 패치가 실제로 문제를 막고 코드를 망가뜨리지 않는지의 비율은 아직 공개할 만큼 모으지 못했어요. 베타 15일 동안 측정해서 알려 드릴게요. 비용·속도 수치도 같아요.

안전하게 쓰도록 만든 장치

인터넷과 분리된 샌드박스

공격 시험은 외부와 연결이 끊긴 전용 네트워크 안에서만 해요. 샌드박스 서버에는 비밀번호·API 키를 두지 않고, 끝나면 지워요.

내가 확인한 것만 실행

분석을 시작하기 전에 계획을 보여 주고 확인을 받아요. 공격 시험도 동의 체크를 해야 시작돼요.

비밀값은 로그에 남기지 않아요

토큰·비밀번호·키는 기록(로그)에 쓰지 않는 것을 개발 규칙으로 정해 두고 지켜요.

베타 전에 알아 두세요

클로즈드 베타라서 아직 제한이 있어요. 아래 내용에 동의하는 분만 사용해 주세요.

  • 초대 전용이에요. 초대받은 계정만 가입·로그인할 수 있어요.
  • 15일 뒤 데이터를 모두 폐기해요. 올린 코드, 분석 결과, 계정 정보가 베타 서버와 함께 지워져요. 필요한 결과는 미리 저장해 두세요.
  • 코드 일부가 AI 제공자로 전송돼요. 분석하려면 코드 조각을 AI 서비스(Anthropic 등)에 보내야 해요. 민감한 코드는 올리지 마세요.
  • 무료 모델을 고르면 그 무료 API의 약관이 적용돼요. 입력한 내용이 해당 제공자의 정책에 따라 처리될 수 있어요.
  • 공격 시험(DAST)은 연습용 표적으로 체험해요. 내 서비스 주소를 검사하는 기능은 베타 중에 추가할 예정이에요.

자주 묻는 질문

누구나 쓸 수 있나요?

아직 아니에요. 초대받은 분만 가입해서 쓸 수 있는 클로즈드 베타예요.

코딩을 몰라도 쓸 수 있나요?

네. 결과를 "무슨 일이 생기는지"로 설명하고 고치는 코드를 같이 보여 줘요. 다만 코드를 적용하기 전에 내용을 한번 읽어 보는 걸 권해요.

내 코드는 어디로 가나요?

분석할 때 코드 조각이 AI 제공자(Anthropic 등)로 전송돼요. 베타 서버의 데이터는 15일 뒤 모두 폐기해요. 비밀번호·키가 들어 있는 파일은 올리지 마세요.

"실제로 뚫리는지 확인"은 내 서비스를 공격하는 건가요?

아니에요. 베타에서는 연습용으로 만든 표적에서만 시험해요. 내 서비스 주소를 검사하는 기능은 베타 중에 추가할 예정이고, 그때도 내 소유임을 확인한 주소만 허용할 계획이에요.

찾은 문제를 다 믿어도 되나요?

아니에요. 측정에서 찾은 문제의 약 3분의 1은 가짜 경고였어요. 위치와 이유를 보고 직접 판단해 주세요.

왜 Windows 경고가 뜨나요?

코드 서명을 하지 않은 베타 앱이라서 그래요. 안내대로 SHA-256 값을 확인한 뒤 실행해 주세요.
